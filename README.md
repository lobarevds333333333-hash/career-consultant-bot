# 🤖 Telegram-бот — помощник карьерного консультанта

Бот на Python (**aiogram 3**) для записи клиентов на консультацию к карьерному консультанту. Перед записью пользователь проходит три теста; **только после успешного прохождения всех тестов** открывается заявка на консультацию.

## ✨ Возможности

- **Приветственное сообщение** с описанием возможностей и reply-меню.
- **Инструкция перед каждым тестом** (цель, количество вопросов, правила).
- **Тест на профориентацию** (модель Дж. Холланда): 12 вопросов — по 2 на каждый тип. В результате — ведущие типы (реалист, исследователь, артист, социальный, предприниматель, организатор), разбор, подходящие сферы и профессии.
- **Тест на тип мышления**: 10 вопросов с 4 вариантами. В результате — доминирующий тип (Аналитик / Креатор / Практик / Критик) и список профессий.
- **Тест на мотивационные факторы**: 10 вопросов с 5 вариантами. В результате — 1–2 ведущих фактора (деньги / свобода / признание / стабильность / смысл), разбор и советы по выбору среды и задач.
- Тесты проходятся **в произвольном порядке**, прогресс и результаты сохраняются в SQLite.
- Кнопка **«📅 Запись на консультацию»** заблокирована, пока не пройдены все три теста.
- **Анкета записи**: имя → удобное время → формат связи (Telegram/WhatsApp) → контакт (телефон или @username) → подтверждение.
- После отправки заявки: сообщение *«Спасибо! Мы свяжемся с вами в ближайшее время»* + **уведомление менеджеру** в Telegram с деталями заявки и сводкой результатов тестов.
- Предложение подписаться на **Telegram-канал по профориентации** (ссылка настраивается).
- Используются и **reply-**, и **inline-кнопки**.

## 🗂 Структура проекта

```
career_bot/
├── bot.py               # точка входа: сборка диспетчера, long polling
├── config.py            # настройки из .env (токен, ID менеджера, ссылка на канал)
├── database.py          # SQLite: пользователи, результаты тестов, заявки
├── tests_data.py        # контент 3 тестов: вопросы, подсчёт баллов, тексты результатов
├── keyboards.py         # все клавиатуры (reply-меню и inline-кнопки)
├── handlers/
│   ├── common.py        # /start, /help, /cancel, пункты меню, fallback
│   ├── tests.py         # прохождение тестов (inline-кнопки вопросов)
│   └── booking.py       # анкета заявки + уведомление менеджеру
├── requirements.txt
├── .env.example         # образец настроек
└── README.md
```

## 🚀 Быстрый старт

1. **Клонировать/скопировать проект** и перейти в папку:
   ```bash
   cd career_bot
   ```
2. **Создать виртуальное окружение** и установить зависимости (Python 3.10+):
   ```bash
   python -m venv .venv
   .venv\Scripts\activate        # Windows
   # source .venv/bin/activate   # Linux/macOS
   pip install -r requirements.txt
   ```
3. **Создать бота**: напишите [@BotFather](https://t.me/BotFather) → `/newbot` → получите токен.
4. **Узнать ID менеджера**: менеджер пишет [@userinfobot](https://t.me/userinfobot) и получает свой ID. *Важно: менеджер должен сначала нажать `/start` у вашего бота, иначе Telegram не разрешит боту писать ему первым.* (Можно указать и ID группы — бот добавляется в группу.)
5. **Создать `.env`** рядом с `bot.py` на основе `.env.example`:
   ```ini
   BOT_TOKEN=1234567890:AAE...ваш_токен_от_BotFather
   MANAGER_CHAT_ID=123456789
   CHANNEL_URL=https://t.me/your_channel
   DB_PATH=career_bot.db
   ```
6. **Запустить**:
   ```bash
   python bot.py
   ```

## ⚙️ Как это работает

```
/start → главное меню (reply-клавиатура)
  ├─ 🧪 Профориентация        → инструкция → 12 вопросов (inline-кнопки) → результат
  ├─ 🧩 Тип мышления           → инструкция → 10 вопросов → результат
  ├─ 💡 Мотивация              → инструкция → 10 вопросов → результат
  ├─ 📊 Мои результаты         → сводка: что пройдено, ведущие типы/факторы
  ├─ 📅 Запись на консультацию → 🔒 до прохождения всех тестов
  │                              после — анкета: имя → время → формат → контакт → подтверждение
  └─ 📢 Наш Telegram-канал     → сообщение с кнопкой-ссылкой
```

- Результаты тестов сохраняются в SQLite (`career_bot.db`), поэтому после перезапуска бота пользователю не нужно проходить их заново.
- При отправке заявки менеджеру приходит сообщение вида:

  ```
  🆕 Новая заявка на консультацию!

  👤 Имя: Анна
  ⏰ Удобное время: будни после 18:00
  💬 Формат связи: WhatsApp
  📞 Контакт: +7 999 123-45-67

  🧑‍💻 Клиент в Telegram: @anna (id: 123456789)

  📊 Результаты тестов:
  🧪 Профориентация: 🎨 Артист (2), 📋 Организатор (2)
  🧩 Тип мышления: 🧮 Аналитик (5 из 10)
  💡 Мотивация: 💰 Деньги (4 из 10), 🕊 Свобода (3 из 10)
  ```

## 🖥 Деплой на сервер (любой VPS)

1. Скопировать проект на сервер, создать venv и установить зависимости (см. выше).
2. Создать `.env`.
3. Настроить автозапуск через **systemd** — файл `/etc/systemd/system/career-bot.service`:

   ```ini
   [Unit]
   Description=Career Consultant Telegram Bot
   After=network.target

   [Service]
   WorkingDirectory=/opt/career_bot
   ExecStart=/opt/career_bot/.venv/bin/python bot.py
   Restart=always
   RestartSec=5

   [Install]
   WantedBy=multi-user.target
   ```

4. Включить и запустить:
   ```bash
   sudo systemctl daemon-reload
   sudo systemctl enable --now career-bot
   sudo systemctl status career-bot    # проверка
   sudo journalctl -u career-bot -f    # логи
   ```

Бот работает через **long polling** — вебхуки, домен и SSL не нужны.

## 🛠 Кастомизация

- **Вопросы, варианты ответов, баллы и тексты результатов** — в `tests_data.py` (изменяются без правки логики: подсчёт построен на словарях).
- **Ссылка на канал** — переменная `CHANNEL_URL` в `.env`.
- **Кому приходят заявки** — `MANAGER_CHAT_ID` в `.env` (личный чат или группа).
- Хранение прогресса между перезапусками — SQLite; состояние анкет (FSM) держится в памяти (`MemoryStorage`) и сбрасывается при рестарте — пользователю достаточно начать анкету заново, результаты тестов при этом не теряются.
